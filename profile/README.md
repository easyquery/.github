# EasyQuery samples

[EasyQuery](https://korzh.com/easyquery?utm_source=github&utm_medium=profile&utm_campaign=org-profile) adds a query builder, ad-hoc reporting and data
filtering to .NET applications. Each repository here holds ready-to-run samples for one platform.
